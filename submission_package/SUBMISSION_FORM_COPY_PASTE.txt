FIELD 3: EXECUTIVE SUMMARY (FOR TEXT BOX SUBMISSION)
--------------------------------------------------------------------------------
While LLMs excel at parsing complex, unstructured commercial agreements and verifying real-world perceptual delivery webhooks (e.g. GitHub CI/CD test runs or logistics waybills), granting an AI agent direct custody of private keys creates catastrophic financial vulnerability: prompt injections, rogue token approvals, velocity drains, and tax non-compliance.

AegisPay solves this by enforcing an institutional Separation of Powers:
1. Probabilistic Perception Off-Chain: An AI Agent engine ingests natural-language contracts, simulates proposed transactions through an ephemeral EVM state-fork dry run, and computes SHA-256 cryptographic attestation hashes upon delivery verification.
2. Deterministic Execution On-Chain: An ERC-4337 smart account (AegisVault.sol) and MilestoneEscrow.sol mathematically bound agent execution via an immutable SessionKeyPolicy ($1,500 USDC per-tx cap, $3,000 USDC rolling 24h velocity cap, recipient allowlist, and a strict bytecode ban on ERC-20 approve()).
3. Automated Regulatory Tax Withholding: Upon milestone settlement, 85% is disbursed to the contractor while 15% is atomically withheld into an isolated Vault Tax Reserve sub-account, locked against AI agent withdrawals.

Under live red-team adversarial attacks (prompt injection $10,000 drain, phishing wallet transfer, malicious infinite approve), the protocol deterministically reverts on-chain with exact custom errors (PerTxSpendLimitExceeded, RecipientNotWhitelisted, FunctionSelectorNotAllowed), achieving a proven $0.00 balance loss.
